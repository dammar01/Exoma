# Open research questions

Each question is a separate research program; none is a roadmap commitment. No
implementation starts from a question alone: it goes through the cycle in
[CONTRACT.md](CONTRACT.md) (question, literature, synthesis, hypothesis, experiment,
decision).

Each question is a record in [questions/](questions/) (`RQ-NN`, DEC-017), with its notes
there. "Status" is `answered` or `unanswered`, never half-answered (DEC-019): an answered
question lists a validated record and the maintainer's decision; what exists for an
unanswered one is in "What exists today" and "Records". "Records" lists tracked records
only; drafts serving a question are named in its notes. A record at schema version 2 or
later names the questions it serves, and the check holds both sides to each other
(CONTRACT.md §14, §16).

Generated from the records by `python tools/maintain/check_research.py --write-inventory`;
the check fails when it is stale.
