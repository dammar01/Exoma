# Exoma 1.2.2

Installer cleanup and rollback preserve concurrent edits when a conflict backup cannot
be saved. An interrupted cleanup reports the recovery file so the user can inspect it
before retrying. Doctor distinguishes runner warnings from blocked calls and reports
incomplete observations when gate logs or Claude session bindings cannot be inspected.

Conditional browser instructions are installed per host. Doctor checks shared
references on Agy-only and Codex-only installs. OpenCode accepts the managed reference
when the home directory is reached through an alias. Session retention also recognizes
a legacy workspace whose only remaining stream is tasks.jsonl.

W3 now holds a selected delegation through receipt acknowledgement. Updated main hosts select the request, collect its original result, then acknowledge it before reading project evidence. Installed-host traces for all four hosts were part of the [release qualification](../../RELEASE.md) gate for this release.
