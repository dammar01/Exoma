# v3.8.4

The provider stable pins move to the current npm releases: opencode `1.19.3` (was `1.18.34`)
and codex `0.163.0` (was `0.154.0`). `install.py --update-providers` now brings an
npm-global CLI to these releases. agy stays on `1.1.13`. No configuration change; the new
pins take effect after `install`. The user-facing documentation is now in English.

Detail: [`docs/reference.md`](../reference.md) — "Provider releases"; decision: DEC-058.

**Behavior changes after install:**

- `doctor` and every call's meta read opencode `1.19.3` and codex `0.163.0` as `stable`; the
  previous releases now read `untested`. Version status stays advisory: no call is blocked.
- `install.py --update-providers --apply` pins to the new releases, records the previous
  release in `provider_update.json`, and prints the pin-back command. `--rollback` still does
  not undo a provider update (DEC-057).

- The intent gate no longer arms on turns the user did not write: a native subagent's
  hand-back, a task notification wrapped in a system reminder, a `source` of `system` or a
  wakeup, or a prompt inside a subagent (DEC-059, CASE-022). Before, those turns could set a
  marker in the middle of `/.execute` and block the main agent and its subagents. A real
  marker still binds subagents. The marker now records `source`, `has_agent_id` and
  `prompt_id`. Details: [`docs/reference.md`](../reference.md) — "Intent mode".

- `/.commit` no longer stops when nothing is staged: main_agent stages changed tracked files
  and untracked files Git does not ignore, one path per argument (never `-A` or `.`), skips
  paths on the canonical secret-file list of `core/policy/secret_patterns.py` (the providers'
  read boundary), and commits only on `yes`; `no` unstages only what it staged. An existing
  staged set is used as is. The skip list is a rule over file names, not a content scanner
  (DEC-060, DEC-061). Details: [`docs/reference.md`](../reference.md) — "Prompt-layer
  contracts".

- A verify test request is bound to the job created for it. Before, a verify whose provider
  call returned `ok:false` or was refused left `verify/tests.json` unconsumed, and the next
  verify ran that earlier choice on a changed tree (CASE-023). Creating a verify job now moves
  the request to `tests.claimed.json` and drops any leftover claim; recovery and attach keep
  it (DEC-062). Details: [`docs/reference.md`](../reference.md) — "Verify mode".

**Also since v3.8.2, not listed in the v3.8.3 notes:**

- `main.py`, `install.py` and `check.py` refuse a Python older than 3.10 with one message
  before any project import. Hooks take the first of `python3`, `python`, `py -3` that runs
  and is >= 3.10 (skipping a WindowsApps alias) and fail open without one.
- Codex resumes a thread with `exec --sandbox` instead of `-c sandbox_mode`: from codex
  0.155.0 the old form made the Windows elevated sandbox refuse every resumed thread; the
  write boundary is kept (CASE-021, DEC-053). A sandbox refusal on a resumed thread now
  carries `meta.reason=resume_sandbox_failed` with resume-specific advice; `error_type` stays
  `sandbox_unavailable` (DEC-024).
- Worker kill is fail-closed: a PID is killed only when its recorded identity matches;
  unverifiable, reused and dead PIDs are skipped with a named reason, and the job is still
  failed and reaped. Process identity and lock code live only in `utils/osutil.py` (DEC-052).
- The `rework` metric counts a task as reworked when a verify round follows a failed or
  incomplete one; `measure_task_outcomes.py` reports feature segments (DEC-051). Details:
  [`docs/evaluation/metrics.md`](../evaluation/metrics.md).

**Documentation:**

- `docs/reference.md`, `docs/limitations.md`, `docs/plans/verify-e2e-playwright-revised.md`,
  the release notes and `CHANGELOG.md` are translated from Indonesian to English. Tokens the
  runtime parses (`question:`, `uncertainty:`, `[PROXY GAGAL]`, `tidak ada`) and the
  Indonesian intent triggers are quoted verbatim. Old heading anchors in `docs/reference.md`
  are kept, so existing links still resolve.
- Unchanged and still Indonesian: the shipped prompt contracts (`dist/config/claude/CLAUDE.md`,
  skills, provider `AGENTS.md`), the intent map, the `prompt/` archive, and the research
  records.
