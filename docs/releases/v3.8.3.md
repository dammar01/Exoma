# v3.8.3

`/.provider` kini menawarkan model yang benar-benar tersedia di CLI provider terpasang,
bukan shortlist yang di-refresh manual dan sudah tertinggal (codex sudah memuat
`gpt-6.1-sol`, agy sudah memuat `gemini-3.8-flash` dan `claude-opus-5-5-*`, sementara
shortlist berhenti di generasi sebelumnya). Model terbaru jadi opsi pertama, dan pilihan
bisa diketik langsung tanpa picker (DEC-051). Tidak ada perubahan breaking pada
konfigurasi; skill dan command baru aktif setelah `install`.

Detail perilaku: [`docs/reference.md`](../reference.md) — "Katalog model `/.provider`".

**Perubahan perilaku yang terasa setelah install:**

- Picker `/.provider` membaca katalog dari CLI provider: opencode (`opencode models` +
  cache models.dev), codex (`~/.codex/models_cache.json`, hanya `visibility: list`), agy
  (`agy models`). Maksimal 20 model, terbaru dulu; sampai 10 ditampilkan sebagai daftar
  bernomor, dan "Other" menerima nomor dari daftar itu.
- "Terbaru": opencode = `release_date` terbaru dalam `family` model aktif; codex =
  `priority` terkecil; agy = versi tertinggi dalam keluarga model aktif. Model terbaru
  ditandai "(Recommended)" dan tetap dikonfirmasi user — tidak ditulis otomatis.
- agy: varian `-low/-medium/-high` dilipat jadi satu model dengan effort = varian. Apply
  menulis id varian (`claude-opus-5-5-high`) dan `effort: null`.
- Validasi effort saat apply memakai katalog live, jadi model yang lebih baru dari
  shortlist diterima tanpa warning. Router dan `validate_provider_config` tetap memakai
  shortlist (tanpa spawn CLI per call).
- CLI tak terbaca → shortlist bawaan (`models_source: static`). Hasil live di-cache 10
  menit; `AI_PROXY_MODEL_CATALOG=static` mematikan pembacaan live.
- Mode langsung: `/.provider <provider> <model> [effort] [routes]`, mis.
  `/.provider codex gpt-6-luna low`. Divalidasi sama dengan picker; ditolak → alasan +
  `next_action`, tidak jatuh ke picker. Deskripsi command, `argument-hint`, dan `/.help`
  menyebut mode ini.
