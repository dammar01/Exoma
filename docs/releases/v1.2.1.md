# Exoma 1.2.1

`exoma jobs clean-stale` explains each job or session claim in the user store.
On Windows, `--apply` can recover an abandoned running or failed job when the
current machine verifies a restart after its last attempt. The command records
the reboot, preserves an existing failure and reports remaining update blockers.
Jobs left by v1.2.0 lack the boot evidence needed for automatic recovery.
Preview and apply both explain the skip and preserve the session lock.
