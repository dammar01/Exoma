# Exoma v1.2.3

Package updates work from a plain directory below an unrelated bare
`.workflow/`. Updates inside configured workspaces also refresh project files.
Explicit workspace upgrades require an existing workspace.

`exoma jobs clean-stale` now applies cleanup and prints one statistics line.
Scripts that used the former read-only default should pass `--dry-run`.
The cleaner checks recorded PID generations, handles a missing session lock,
and preserves terminal job history. Live and unverifiable ownership keep
blocking update. The root CLI help groups commands by purpose, with dedicated
help for package update, workspace upgrade and job cleanup.

See the [installation guide](../installation.md) for recovery from an older
blocked installation and the [CLI reference](../reference.md) for cleanup counters.
